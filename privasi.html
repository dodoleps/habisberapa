Kebijakan Privasi

Berlaku sejak 7 Oktober 2026

Ringkasnya
  • Catatan keuangan Anda (transaksi, dompet, kategori) tersimpan di HP Anda sendiri, bukan di server kami.
  • Saat memakai fitur AI suara, rekaman atau teks Anda dikirim untuk diubah menjadi transaksi, lalu tidak kami simpan.
  • Kami hanya menyimpan email untuk login, statistik pemakaian tanpa isi keuangan, dan masukan yang Anda kirim.

1. Data yang tersimpan di HP Anda

Transaksi, dompet, kategori, pilihan warna, dan pengaturan aplikasi disimpan di penyimpanan browser pada perangkat Anda. Data ini tidak dikirim ke server kami. Karena itu, kami tidak dapat memulihkannya bila HP hilang, rusak, atau data browser dihapus. Gunakan menu Atur → Simpan cadangan secara berkala.

2. Data yang diproses server kami

  • Akun Google — email dan nama dari Google Sign-In, untuk masuk ke aplikasi. Kami tidak menerima kata sandi Anda.
  • Rekaman suara atau teks yang Anda ucapkan/ketik untuk dicatat, beserta daftar nama dompet dan kategori Anda, dikirim ke server kami lalu diteruskan ke Google Gemini untuk diubah menjadi transaksi. Server kami tidak menyimpan rekaman, teks, maupun hasilnya.
  • Statistik pemakaian — kode acak yang dibuat dari email Anda (bukan email itu sendiri), tanggal pemakaian, dan jumlah catatan AI per hari. Tidak berisi nominal atau isi transaksi.
  • Masukan yang Anda kirim lewat menu Kirim masukan, beserta email Anda, agar dapat kami tindak lanjuti.

3. Tentang Google Gemini (AI)

Saat ini aplikasi memakai layanan Gemini API versi gratis. Pada layanan gratis, Google dapat menggunakan konten yang dikirim untuk meningkatkan produknya, sesuai Ketentuan Gemini API. Hindari menyebut informasi yang sangat pribadi (nomor rekening, PIN, kata sandi) saat merekam suara. Bila nanti kami beralih ke layanan berbayar, kebijakan ini akan diperbarui.

4. Pihak yang membantu kami

  • Google — login (Google Sign-In) dan AI (Gemini).
  • Cloudflare — menjalankan server kami (Workers & database D1).
  • GitHub Pages — tempat tampilan aplikasi diunduh.
  • cdnjs — pustaka untuk membuat file PDF/Excel, diunduh saat Anda pertama kali mengekspor.

Kami tidak menjual data Anda dan tidak memakainya untuk iklan.

5. Hak Anda

Sesuai Undang-Undang Pelindungan Data Pribadi (UU No. 27 Tahun 2022), Anda berhak mengakses, memperbaiki, dan menghapus data pribadi Anda.

  • Data di HP — ekspor kapan saja lewat Simpan cadangan atau unduh laporan, dan hapus lewat Atur → Hapus semua data di HP ini.
  • Data di server (statistik pemakaian & masukan) — minta salinan atau penghapusan melalui menu Kirim masukan.
  • Akses Google — Anda dapat mencabut akses aplikasi kapan saja di pengaturan akun Google.

6. Penyimpanan & keamanan

Komunikasi dengan server memakai koneksi terenkripsi (HTTPS). Sesi login berlaku 30 hari di setiap perangkat. Statistik pemakaian dan masukan disimpan selama aplikasi masih dalam tahap uji coba, lalu ditinjau ulang.

7. Perubahan kebijakan

Kebijakan ini dapat berubah, misalnya saat fitur premium atau penyimpanan cloud ditambahkan. Tanggal berlaku di bagian atas halaman akan diperbarui, dan perubahan penting akan diberitahukan di aplikasi.
